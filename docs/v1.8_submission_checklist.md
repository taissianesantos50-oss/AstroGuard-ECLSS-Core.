## Final status categories

Use only these categories when reporting project status:

- **IMPLEMENTED** — present in the repository and reproducibly executable or inspectable.
- **SIMULATED** — intentionally generated demonstration behavior or data.
- **DOCUMENTED** — defined as a specification or presentation artifact.
- **PROPOSED / FUTURE** — not part of the current implementation.

This vocabulary prevents future capabilities from being mistaken for completed engineering validation.
