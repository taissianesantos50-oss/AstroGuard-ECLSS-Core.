# AstroGuard v1.4 — Human Health Monitoring Layer

## Purpose
Version 1.4 extends the ECLSS simulation with a human-health telemetry layer. The prototype demonstrates how environmental telemetry and simulated physiological indicators can be evaluated together.

## Indicators
- Heart rate (bpm)
- Blood oxygen saturation / SpO2 (%)
- Body temperature (C)
- Respiratory rate (breaths/min)
- Fatigue index (0–1)
- Well-being index (0–1)

## Decision states
NORMAL — no illustrative rule triggered.
ATTENTION — multiple illustrative indicators require attention.
CRITICAL — an illustrative critical condition is detected.

## Limitation
This is a research and simulation prototype. Physiological values and thresholds are illustrative parameters only. They are not clinical limits, diagnostic criteria, Artemis mission measurements, or flight-qualified safety logic.

A validated implementation would require biomedical datasets, expert review, verification/validation, human-factors evaluation, and applicable regulatory and mission certification processes.

## Architecture
Environment → Human telemetry → Decision engine → CSV event record → Visualization layer
