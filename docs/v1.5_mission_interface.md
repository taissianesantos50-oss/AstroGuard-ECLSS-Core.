# v1.5 Mission Interface Specification

## Purpose

The AstroGuard v1.5 interface is a conceptual 3D mission-telemetry display built on the verified v1.4 CSV contract.

## Interface regions

1. **3D mission space** — animated trajectory representing the relationship between mission time, environmental stress and human stress.
2. **ASTROGUARD CORE panel** — current telemetry snapshot.
3. **MISSION STATUS panel** — software state and high-level environment/human-load indicators.
4. **Spacecraft marker** — conceptual vehicle geometry used only for visual orientation.

## State presentation

- NORMAL: nominal software state.
- ATTENTION: attention-required software state.
- CRITICAL: critical software state.

These labels are inherited from v1.4. The interface does not independently diagnose the astronaut or issue commands.

## Data integrity

The interface is read-only with respect to telemetry. It does not alter the CSV and does not send actuator commands.

## Scientific boundary

Environmental and human-stress values are derived visualization quantities. They are not clinical scores, medical diagnoses or flight-qualified safety metrics.
