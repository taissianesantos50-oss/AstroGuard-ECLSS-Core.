# AstroGuard v1.7 — Final Demonstration Video Production Script

**Project:** AstroGuard-ECLSS-Core  
**Developer:** Taissiane Thais dos Santos  
**Target:** 2–3 minute final technical demonstration  
**Classification:** SIMULATION · RESEARCH PROTOTYPE

## Production objective

Produce a concise technical demonstration that shows the complete AstroGuard data path: environmental telemetry + synthetic human telemetry → deterministic health evaluation → NORMAL / ATTENTION / CRITICAL → telemetry storage → 3D visualization → web mission dashboard.

## Scene 1 — Opening · 00:00–00:10

**Visual:** AstroGuard title over the official v1.8 architecture visual or dashboard background.

**On screen:**

ASTROGUARD  
Human Health Monitoring for Long-Duration Space Missions  
SIMULATION · RESEARCH PROTOTYPE  
Taissiane Thais dos Santos

**Narration:**

> When an astronaut is far from Earth, mission awareness must include both the spacecraft environment and the human inside it.

## Scene 2 — Environmental layer · 00:10–00:25

**Capture:** Run the C simulation and show environmental telemetry.

**Highlight:** O2, pressure, temperature, O2 valve and heater.

**Narration:**

> AstroGuard begins with an environmental simulation that tracks oxygen, pressure, temperature and actuator states in a deterministic software core.

## Scene 3 — Human-health layer · 00:25–00:45

**Capture:** Show the human telemetry fields in the terminal, CSV or dashboard.

**Highlight:** heart rate, SpO2, body temperature, respiratory rate, fatigue and wellbeing.

**Narration:**

> The human-health layer adds synthetic physiological telemetry, allowing the same mission timeline to represent both environmental conditions and the changing state of the crew member.

## Scene 4 — State transition · 00:45–01:15

**Capture:** Dashboard playback.

**Required sequence:**

- t=0–7 s — NORMAL
- t=8–13 s — ATTENTION
- t=14–20 s — CRITICAL

**Narration:**

> The verification scenario begins in a normal state. As the synthetic telemetry changes, deterministic rules move the software into attention and then critical states. Identical inputs produce identical classifications.

## Scene 5 — Decision support · 01:15–01:35

**Capture:** Alert panel, environmental state, human load, actuator states and current JSON telemetry packet.

**Narration:**

> The mission interface brings the state, telemetry and actuator information together so that changing conditions can be inspected in one place. These outputs are prototype decision-support information, not medical diagnoses.

## Scene 6 — 3D visualization · 01:35–01:55

**Capture:** v1.5 Python visualization.

**Show:** mission time, trajectory, current health state, environmental representation and human representation.

**Narration:**

> A complementary three-dimensional view adds mission context to the telemetry while keeping visualization separate from the deterministic decision engine.

## Scene 7 — Web dashboard · 01:55–02:10

**Capture:** Full v1.6 dashboard, followed by close views of mission state, human telemetry, environment, alert panel and current packet.

**Narration:**

> The browser dashboard consolidates the prototype into a readable mission-monitoring interface that can be demonstrated without an external build step.

## Scene 8 — Architecture · 02:10–02:25

**Visual:** `docs/v1.8_architecture_diagram.svg`

**Narration:**

> The architecture connects environmental simulation, human telemetry, health monitoring, deterministic classification, telemetry storage and two presentation layers: 3D visualization and the web dashboard.

## Scene 9 — Scientific boundary · 02:25–02:35

**On screen:**

RESEARCH / SIMULATION PROTOTYPE  
Synthetic physiological telemetry  
Prototype software thresholds  
Not a medical device  
Not flight-qualified  
No real astronaut telemetry

**Narration:**

> AstroGuard is a research and simulation prototype. Its physiological telemetry is synthetic, and its software thresholds are demonstration and verification parameters rather than clinical or flight-certified limits.

## Scene 10 — Closing · 02:35–02:50

**On screen:**

ASTROGUARD  
MONITOR THE ENVIRONMENT.
