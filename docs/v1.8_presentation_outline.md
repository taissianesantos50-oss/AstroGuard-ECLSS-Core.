## Slide 2 — The Human Problem

Long-duration missions create a monitoring challenge: environmental telemetry describes the spacecraft, while human telemetry describes the person operating and living inside that environment.

AstroGuard explores a software architecture that places both dimensions within one mission-monitoring workflow.

## Slide 3 — Mission Scenario

The prototype uses synthetic telemetry to demonstrate three deterministic software states:

**NORMAL → ATTENTION → CRITICAL**

The scenario is intentionally constructed for software verification and demonstration.

## Slide 13 — Limitations and Next Steps

### Current limitations

- synthetic physiological telemetry
- prototype thresholds
- no clinical validation
- no flight qualification
- no real astronaut data
- no operational spacecraft control

### Potential future work

- validated physiological models
- uncertainty and confidence handling
- authenticated telemetry
- fault-injection testing
- hardware-in-the-loop testing
- human-factors evaluation
- formal verification
- integration with validated mission data standards

These are future research directions, not current capabilities.
