# v1.5 Architecture - Mission Telemetry Visualization

ASTROGUARD v1.5
|

|  +- Environment: O2 / Pressure / Temp
|  +- Human: HR / SpO2 / Resp / Fatigue / Well-being
|
+- CSV parser
|
+- Normalization / visualization indices
|
+- 3D Mission Visualization
   +- Environment view
   +- Human view
   +- Health state: NORMAL / ATTENTION / CRITICAL
   +- Mission timeline

## Design principle

The visualization consumes telemetry; it does not become the decision engine. v1.4 remains responsible for health-state evaluation.
