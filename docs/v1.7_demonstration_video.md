# AstroGuard v1.7 — Demonstration Video Specification

**Project:** AstroGuard-ECLSS-Core  
**Developer:** Taissiane Thais dos Santos  
**Version:** 1.7 — Demonstration Video

## Purpose

v1.7 defines the official demonstration sequence for presenting the AstroGuard prototype from simulation startup through human-health monitoring, alert transition and mission visualization.

The video should communicate the engineering flow without presenting the prototype as flight-qualified or clinically validated.

## Demonstration sequence

### Scene 1 — Mission initialization
Display:
- ASTROGUARD
- Human Health Monitoring for Long-Duration Space Missions
- SIMULATION · RESEARCH PROTOTYPE
- Developer: Taissiane Thais dos Santos

Narration:
> When the astronaut is far from Earth, mission awareness must include both the spacecraft environment and the human inside it.

### Scene 2 — Environmental telemetry
Show:
- O2
- Pressure
- Temperature
- Actuator states

Purpose:
Establish the ECLSS/environmental foundation inherited from earlier versions.

### Scene 3 — Human telemetry
Show:
- Heart rate
- SpO2
- Respiratory rate
- Fatigue
- Well-being

Purpose:
Introduce the v1.4 Human Health Monitoring Layer.

### Scene 4 — State transition
Run the verified synthetic scenario:
- 0–7 s: NORMAL
- 8–13 s: ATTENTION
- 14–20 s: CRITICAL

Show the dashboard state banner changing with the telemetry.

### Scene 5 — Decision-support interface
Show:
- Alert panel
- Environment status
- Human load
- O2 valve
- Heater
- Current telemetry packet

Clarification:
These are prototype software states and telemetry displays, not medical diagnoses.

### Scene 6 — 3D mission visualization
Show the v1.5 interface:
- Mission time
- Environmental stress representation
- Human stress representation
- Current health state
- Conceptual spacecraft marker

### Scene 7 — Web mission dashboard
Show the v1.6 browser interface as the consolidated presentation layer.

Recommended shot:
Start at the full dashboard, then zoom/crop into:
1. Mission state
2. Human telemetry
3. Environment
4. Alert panel
5. Telemetry packet

### Scene 8 — Technical architecture
Display:

v1.3 ECLSS foundation
→ v1.4 Human Health Monitoring
→ v1.5 3D Mission Visualization
→ v1.6 Web Mission Dashboard
→ v1.7 Demonstration

### Scene 9 — Scientific boundary
On-screen text:

> RESEARCH / SIMULATION PROTOTYPE  
> Synthetic telemetry  
> Visualization and software-verification thresholds  
> Not a medical device  
> Not flight-qualified

This scene is important for technical credibility.

### Scene 10 — Closing
Display:

**ASTROGUARD**

Monitor the environment.  
Understand the human.  
Support the mission.

Final line:

> Space exploration is not only about keeping a spacecraft alive. It is about keeping the human inside it healthy enough to continue the mission.

The duration is a production target, not a requirement.

## Important presentation rule

Do not describe synthetic telemetry as real astronaut data. Do not describe prototype thresholds as clinical limits. Do not claim NASA, Artemis or flight certification validation unless separately documented by an authoritative source.
