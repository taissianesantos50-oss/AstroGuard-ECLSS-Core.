# AstroGuard v1.5 - 3D Mission Telemetry Visualization

**Developer:** Taissiane Thais dos Santos
**Status:** Research/simulation prototype

## Objective
v1.5 converts the v1.4 CSV telemetry stream into a visual mission interface. It makes environmental conditions, human physiological indicators and health-state transitions observable during a simulated mission run.

This is a telemetry visualization layer, not a clinical monitoring system.

## Visual model
- X axis: mission time.
- Y axis: normalized environmental stress from O2, pressure and temperature.
- Z axis: normalized human-stress representation from SpO2, heart rate, respiratory rate, fatigue and well-being.
- Health state: retained from the v1.4 decision engine.
- Telemetry overlay: current mission time, health state, heart rate, SpO2, O2 and pressure.

The stress values are visualization indices created by this prototype. They are not medical scores.

## Run
python -m pip install -r requirements-v1.5.txt
python src/astroguard_v1_5.py

A custom CSV can be supplied as the first command-line argument.

## Verification target
The current v1.4 sample demonstrates NORMAL -> ATTENTION -> CRITICAL. v1.5 makes that transition visible as the animated telemetry trajectory progresses.

## Engineering boundaries
- Visualization consumes telemetry; it does not issue actuator commands.
- It does not diagnose health conditions.
- It does not claim clinical validation.
- Derived stress indices are visualization-only quantities.
